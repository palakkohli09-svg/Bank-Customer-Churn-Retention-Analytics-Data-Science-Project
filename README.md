# Bank-Customer-Churn-Retention-Analytics-Data-Science-Project
Built a machine learning project to analyze and predict customer churn in the banking sector. Performed EDA, data preprocessing, SQL analysis, classification modeling, churn probability prediction, and Power BI dashboarding to identify high-risk customers and generate actionable retention insights.

## PROJECT OVERVIEW
This project analyzes customer churn in the banking sector using data analytics and machine learning. The goal is to identify customers who are likely to leave the bank, understand the factors associated with churn, and support customer retention decisions.

## OBJECTIVES
- Analyze customer characteristics and churn patterns
- Identify factors associated with customer churn
- Build a machine learning model to predict churn probability
- Categorize customers into different risk levels
- Create an interactive Power BI dashboard for business insights

## TECHNOLOGIES USED
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SQL
- Power BI

## PROJECT OVERFLOW
1. Data Collection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis (EDA)
4. SQL Data Analysis
5. Feature Engineering
6. Machine Learning Model Development
7. Churn Probability Prediction
8. Customer Risk Classification
9. Power BI Dashboard Development

## MACHINE LEARNING
The project uses machine learning to predict the probability of customer churn.

The model output is used to categorize customers into:

- High Risk
- Medium Risk
- Low Risk

## POWER BI DASHBOARD
The dashboard provides insights into:

- Customer churn
- Customer risk levels
- Churn probability
- Churn by geography
- Customer demographics
- Credit score
- Account balance
- Tenure
- Number of products
- Customer activity

- Risk segmentation makes it easier to prioritize customer analysis.
